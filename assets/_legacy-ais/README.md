# Legacy — AI Automation Society (AIS)

These are archived assets from the original AIS worked-example that shipped with this workspace. They are retained for reference only and are **not** part of the Kingston Frameworks brand system.

## What's here

- `AIS Logo PNG.png` — AIS wordmark with blue outer glow
- `AIS Background.png` — background texture used in AIS scenes
- `AIS Brand Guideline Small.jpg` — AIS brand reference one-pager
- `DESIGN.ais-example.md` — the full AIS visual-identity spec

## Do not use for Kingston Frameworks production

AIS colors, fonts, and iconography are unrelated to Kingston Frameworks. For Kingston production, use:

- `assets/brand-tokens.css` (root) — Kingston CSS custom props
- `DESIGN.kingston.md` (workspace root) — Kingston visual identity

## Why keep it

Several `video-projects/aisoc-*` and `golden-ratio-demo` projects still reference these assets historically. Those projects are archived as legacy video work; see each project's `LEGACY.md`. Rebuilding any of them under the Kingston brand means starting from scratch with the Kingston tokens — not find-and-replace.

The AIS brand assets remain the property of AI Automation Society and are not licensed for reuse.
