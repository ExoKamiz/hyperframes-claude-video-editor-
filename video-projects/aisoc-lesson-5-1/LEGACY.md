# LEGACY — AIS archive

This project is an archived AIS (AI Automation Society) worked-example. It is **not** part of Kingston Frameworks production and should not be used as a template for new Kingston video work.

## What to expect

- Palette: AIS deep-navy + cyan-blue (`#37bdf8`) + orange (`#f09025`) — unrelated to Kingston.
- Typography: Roboto Mono + Montserrat with AIS-specific pairings.
- Copy: references to `@aiautomationsociety`, AIS pillars, community language.
- Brand tokens: project-local `assets/brand-tokens.css` uses `--ais-*` custom props — intentionally left as the AIS palette.
- Logo assets: AIS wordmark + glow recipe.

## If you need to rebuild something similar for Kingston

Do not find-and-replace. Start a fresh project under `video-projects/<kingston-slug>/`, import Kingston brand tokens, and follow `DESIGN.kingston.md`. The AIS aesthetic (command-center, cyan-on-navy, mono-heavy) is the opposite of Kingston's restrained gallery aesthetic.

## Canonical Kingston references

- `DESIGN.kingston.md` (workspace root) — visual identity
- `assets/brand-tokens.css` (workspace root) — Kingston CSS custom props
- `assets/Kingston_Logo.svg` (workspace root) — placeholder wordmark
